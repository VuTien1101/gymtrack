========================== CHƯA LÀM ===========================================
chi tiết bài tập

quên mk => gửi otp về sđt

bấm mua gói/gia hạn => tạo mã QR



Ê ý tưởng này **làm được và khá hợp để làm project portfolio**, nhất là nếu m muốn đi Front-end nhưng vẫn muốn thể hiện Full-stack + Database.

T nghĩ đừng chỉ làm app “đếm ngày đi gym”, mà biến nó thành **Gym Membership & Attendance Management App** — kiểu app cho **người tập + chi nhánh + quản lý phòng gym**.

## 1. Concept tổng thể

Tên tạm: **GymTrack**

Có 2 loại tài khoản:

* 👤 **Member** — người đi tập
* 🏢 **Admin/Staff** — nhân viên/quản lý chi nhánh

Luồng chính:

```text
Đăng ký
   ↓
Mua/đăng ký gói tập
   ↓
Có ngày bắt đầu + ngày hết hạn
   ↓
Check-in mỗi lần đến gym
   ↓
Theo dõi lịch sử tập
   ↓
Xem số người đang tập tại chi nhánh
   ↓
Thống kê tháng
```

# 3. Check-in

Có thể làm nhiều cách.

### Cách 1 — QR Code

Ở cửa phòng gym có QR:

```text
        ┌─────────────┐
        │   QR CODE   │
        │             │
        │    ████     │
        │  █  ██ █    │
        └─────────────┘
```

Member mở app → Scan QR → check-in.

Database lưu:

```text
member_id
branch_id
check_in_time
check_out_time
```

Sau đó:

```text
🟢 Đang tập

Check-in
10:32 AM

Thời gian:
01:24:36
```

Có thể thêm **Check-out**.

# 16. Riêng cái "đang có bao nhiêu người" làm realtime

Cái này m có thể dùng:

**Socket.IO**

Ví dụ:

```text
Member A check-in
       ↓
Backend
       ↓
Socket.IO
       ↓
Các điện thoại đang xem branch
       ↓
47 → 48 người
```

Không cần refresh app.

Đây là một điểm **rất đáng đưa vào CV**.

## 20. Kiến trúc tổng thể

T sẽ hướng project theo:

```text
                    ┌──────────────┐
                    │ React Native │
                    │   Mobile App │
                    └──────┬───────┘
                           │
                      REST API
                           │
                    ┌──────▼───────┐
                    │ Node.js      │
                    │ Express      │
                    └──────┬───────┘
                           │
             ┌─────────────┼─────────────┐
             │             │             │
          MySQL        Socket.IO      JWT Auth
             │             │
             │       Realtime
             │             │
             └─────────────┘
```

**Nếu m làm project này để vừa học vừa bỏ vào CV**, t sẽ không bắt đầu code ngay. Bước đầu tiên nên là **chốt requirements + thiết kế database + API + wireframe khoảng 10–12 màn hình**, rồi mới code. Như vậy làm sẽ đỡ rối và nhìn giống một project thực tế hơn.
